# F1 观赛助手 · 开发文档

版本：v2.0　日期：2026-10-06　形态：**Electron 桌面应用**（Windows）
上一版：v1.0「F1 Hub」静态展示站（原生 HTML/CSS/ES Module + 模拟数据）

---

## 1. 项目概述

F1 观赛助手是一个常驻桌面的 F1 观赛工具。它不再是展示型页面，而是一个真的助手：

- **真实数据**：2026 赛季 23 站赛历、23 位车手与 11 支车队积分、16 站完赛成绩/排位/进站记录，全部来自公开接口，没有一条编造数据。
- **离线可用**：内置数据快照，断网时首屏毫秒级出现，联网后自动补齐实时积分榜。
- **会提醒**：按本机时区倒计时到每一节练习/排位/冲刺/正赛，开赛前按设定提前量弹系统通知。
- **关注置顶**：收藏车队或车手，积分榜与赛历会高亮置顶。
- **F1 官网视觉**：carbon 深底、克制的高饱和红、方正卡片与表格主导的信息密度。

## 2. 本次重构做了什么

### 2.0 视觉基准的修正（重要）

第一轮实现把 F1 官网理解成了「carbon 深色主导」，用户对照 formula1.com 实拍截图后指出还原度不足。**官网的实际默认呈现是亮色**：

| 元素 | 官网做法（现已对齐） |
|---|---|
| 页面底色 | `#f3f3f4`，卡片纯白 `#fff`，1px `#dcdcdf` 描边 |
| 顶部两条黑条 | 黑条一 `#15151e`（站内导航，当前项 3px 红下划线）+ 黑条二 `#000`（当前分站 `R17 / 09 – 11 OCT / 🇸🇬 新加坡 ›` + `● MY TIME / TRACK TIME` 双时钟） |
| 强调色 | `#e10600`：当前页签下划线、下一站整卡红底白字、红色胶囊主按钮 |
| 标题 | 大字号全大写窄体（`clamp(30px,4.2vw,56px)` / 900 / `letter-spacing:-.025em`） |
| 赛历卡片 | `ROUND NN` 小标签 + 右上日期胶囊 `09 – 11 OCT` + 国旗与大字号国家名 + `FORMULA 1 … GRAND PRIX 2026` 小号大写副标题 + 底部 1ST/2ND/3RD 领奖台行（三位车手代码 + 时间） |
| 日期口径 | **按赛道当地日期**（`CIRCUIT_TZ` + `Intl.DateTimeFormat`），不随用户时区偏移而错日 |
| 命名口径 | **专有名词一律英文**（国家 / 城市 / 赛道 / 车手 / 车队 / 分站名），与官网一致；**界面标签保留中文**（导航、按钮、面板标题、设置项）。国家用两位代码徽标（`SG`/`MY`/`AZ`）而非国旗 emoji —— Windows 不含彩色旗帜字体，emoji 会退化成两个字母 |

因此主题策略改为**显式主题**：`:root` 即亮色，暗色只在 `:root[data-theme='dark']`，跟随系统只在 `:root[data-theme='system']` 的媒体查询内 —— 不再让操作系统的暗色偏好顶掉官网观感。并加了设置迁移（`SETTINGS_VERSION`，初版为 2、**当前为 3**）：把早期默认值 `'system'` 视为「未显式选择」，统一迁移到 `'light'`。

### 2.0.1 中文排版的关键修正

第一轮实现里，大标题的拉丁部分有 F1 味、中文部分却是系统默认的微软雅黑，割裂感很强（「AI 味」的根源）。原因很具体：**Titillium Web 只有拉丁字形**，所有中文都回退到了系统字体 —— 而官网是纯英文站，不存在这个问题。

字体选型经过三轮否决后定案（期间试过并废弃：得意黑 Smiley Sans —— 通篇倾斜、正文不耐看且只有单一字重；MiSans —— 普通几何黑体不够风格化；思源黑体/Noto Sans SC —— 中性 UI 黑体，与 F1 品牌字不同类）：

1. **专有名词改英文**，让最显眼的大字（国家名、车手姓氏、分站名）落在 Titillium Web 上；
2. **中文改用阿里巴巴普惠体**（`assets/fonts/puhuiti/PuHuiTi-{Regular,Medium,Bold,Heavy}.otf`）—— 与 F1 官方海报中文同类的厚重方正黑体，**4 个真实字重**（400/500/700/900），不再依赖合成加粗；
3. 用 **`unicode-range`** 把普惠体的作用域限制在 CJK（`U+2E80-2EFF, U+3000-303F, …, U+4E00-9FFF, …`），拉丁字母继续交给 Titillium Web；
4. 新增 `--font-display` 令牌，标题族（`.display`/`.band-title`/`.card-title`/`.card-country`/`.dh-title`/导航/按钮/表头/标签…）统一走它；
5. 字形覆盖经 `tools/font-preview.py` 校验：**148 个应用内实际用到的汉字在 4 个字重下全部覆盖**（比对「私用区必然缺字」的 `.notdef` 位图判定）。

### 2.2 修复的缺陷

1. **倒计时崩溃**：旧 `components.js` 的 `startCountdown` 在 `const timer = setInterval(...)` 之前就同步调用 `render()`，目标时间已过时会走 `clearInterval(timer)` 分支而 `timer` 仍在 TDZ，抛 `ReferenceError: Cannot access 'timer' before initialization`（已用 Node 复现）。现改为纯函数 `countdownCells()` + 全局单心跳，不再持有裸定时器。
2. **定时器泄漏**：旧实现每次渲染焦点模块都新建 interval 且从不清理。现为全局单 `setInterval` + `onTick` 可退订。
3. **HTML 拼接零转义**（XSS 风险）：现所有动态文本经 `escapeHtml`，所有链接经 `safeUrl` 白名单（拦 `javascript:`/`data:`/控制字符绕过）。
4. **空数据崩溃**：`getFeaturedRace()` 曾可能返回 `undefined` 导致 `race.name` 报错，且页面只 `console.error` 白屏。现全部渲染函数带空值防护，失败时显示可读错误态。
5. **内联 `onerror`**：旧详情页头图用 `onerror="..."` 内联 JS（CSP 不友好）。现改为挂载后 `addEventListener`，并在 CSS 中用 `.fallback` 类兜底。
6. **视图逻辑散落在控制器**：旧 `race-detail.js` 75 行里 60 行是渲染代码。现全部收敛到 `assets/js/ui/*`，控制器只做取数、挂事件、调度。
7. **`USE_MOCK` 是 const，"一键切换"实际要改源码**：现为运行时配置（`window.__F1_CONFIG__` 与 `?mock=`/`?api=` 查询参数），且真实链路已被自检真实执行过。
8. **跨页锚点失效**：旧 `pages/race.html` 导航指向 `../index.html#calendar`，而首页是默认收起的抽屉，点进去看不到目标。
9. **订阅时序缺陷**（重构中自查发现）：`subscribeSettings` 曾注册在 `await Promise.allSettled([天气, 新闻])` 之后，导致启动阶段点击关注「写盘成功但界面不更新」。现改为**先注册订阅，再做任何网络请求**。
10. **网络抖动被误判为离线**：实测 `api.jolpi.ca` 偶发 `Connect Timeout Error`（Cloudflare 连接超时 10s）。现网络层失败重试一次（间隔 700ms），失败仍保留旧缓存。
11. **快照生成丢数据**：`tools/fetch-data.mjs` 曾在镜像超时时把已采到的某站成绩写空。现读入上一版快照做兜底，并打印「新采 N 站 / 沿用 M 站 / 仍缺失」。
12. **车手中文名静默回退英文**：`DRIVER_ZH` 的键曾用姓氏（`verstappen`、`lindblad`），而 Ergast 的 `driverId` 实为 `max_verstappen`、`arvid_lindblad`，导致这两人的中文名一直显示英文姓。已修正并重新生成快照。

## 3. 技术选型

| 决策点 | 选择 | 理由 |
|---|---|---|
| 桌面壳 | **Electron 38** | 本机无 Rust 工具链（Tauri 不可行）；Electron 有本地缓存可离线安装；托盘/系统通知/开机自启等后续能力齐备 |
| 渲染层 | **原生 HTML/CSS/ES Module，零构建** | 保留 v1.0 的核心优点：改完刷新即生效，没有构建等待 |
| 自定义协议 | `app://f1hub/` 取代 `file://` | `file://` 是不透明源，ES Module 与 `fetch` 都会被 CORS 拦掉，而读取内置快照必须用 `fetch` |
| 网络出口 | 渲染层 → IPC → **主进程 `net.fetch`** | `api.jolpi.ca` 没有 `Access-Control-Allow-Origin`，渲染层直连会被拦；主进程代理还便于加域名白名单与响应缓存 |
| 数据源 | jolpi.ca（Ergast 镜像）+ Open-Meteo + F1 官方 RSS | 三者均免 API key |
| 字体 | Titillium Web（拉丁，SIL OFL 1.1）+ 阿里巴巴普惠体 Alibaba PuHuiTi（中文） | 官网正文即 Titillium Web；**F1 的 `Formula1` 本身就是 Titillium 的定制版**（官网同时挂 Titillium 作后备），这是合法可得的最接近方案。官网的 `Formula1`/`Formula1Wide` 为专有字体**不可分发**。中文侧：F1 **没有中文站点**（`/zh`、`/zh-cn`、`/zh-hans`、`/cn` 全 404），不存在官方 CJK 搭配；参照 F1 官方海报里的中文（厚重、方正、端点平切、略窄的「冲击力标题字」），选定阿里巴巴普惠体 —— 中文体育/营销图的常用字，气质同类。用 `unicode-range` 分工：拉丁走 Titillium，CJK 走普惠体，避免两套字形在同一行抢戏 |
| 打包 | electron-builder（NSIS + 免安装目录） | 用 `electronDist` 指向已解包的本地 Electron，避免联网下载 |

## 5. 数据来源与模型

| 数据 | 来源 | 端点 |
|---|---|---|
| 赛历（含每节练习/排位/冲刺时间） | jolpi.ca Ergast 镜像 | `/ergast/f1/2026/races.json` |
| 车手/车队积分 | 同上 | `/driverStandings.json`、`/constructorStandings.json` |
| 分站成绩/排位/进站 | 同上 | `/{round}/results.json`、`/qualifying.json`、`/pitstops.json` |
| 赛道坐标与天气 | Open-Meteo | `/v1/forecast?latitude=&longitude=&hourly=…&timezone=auto` |
| 新闻 | Formula 1 官方 | `https://www.formula1.com/en/latest/all.xml` |

- **离线优先**：`loadSeason()` 只读内置快照、不等待网络；`refreshLive()` 在后台取实时积分榜，成功才原地重绘。
- **状态运行时重算**：分站「已完赛/待赛」不沿用快照里的旧标记，而按当前时间重新判定，因此快照放置多久都不会显示错。
- **会话时间是 UTC**，界面统一换算到本机时区并显式标注（`tzLabel()`）；天气对齐用接口返回的 `utc_offset_seconds` 做偏移，避免时区错位。
- **不编造字段**：Ergast 不提供赛道长度/弯数/圈速纪录，因此详情页不再展示这些；进站与轮胎信息改为从真实 `pitstops` 统计得出。

## 6. 观赛助手能力

- **全会话倒计时**：下一站自动选中「本周未结束的那一节」，倒计时到大奖赛周末的任意会话（FP1/SQ/Sprint/Q/Race），并显示开赛时刻与本机时区。
- **赛前提醒**：`domain/schedule.js` 的提醒引擎每 60 秒检查一次是否进入提醒窗口；提前量 5/10/15/30/60 分钟可选；已提醒记录存在 `localStorage`，不重复打扰。设置面板可一键「测试通知」。
- **关注置顶**：点击积分榜星标收藏车队/车手，写盘后立即重绘（`is-fav` 高亮 + 星标点亮），赛历中相关车队登台的分站也会标记。
- **明暗主题**：跟随系统或手动指定；Electron 原生标题栏覆盖层颜色随主题同步。

## 7. 工程流程

```bash
pnpm install                     # 安装依赖（已配好 hoisted + allowBuilds）
pwsh -File tools/setup-electron.ps1   # 从本地缓存解包 Electron 二进制（见 §7.1）
node tools/fetch-data.mjs        # 重新采集真实数据快照
node tools/launch.mjs            # 启动应用
node tools/launch.mjs --selftest # 无头式端到端自检
node tools/check-page.mjs home   # 首页结构与交互断言（另有 schedule/standings/results/race 四个子页）
node tools/check-pages.mjs       # 详情页 + 数据层 + 转义断言
pnpm run pack                    # 免安装目录 dist/win-unpacked
pnpm run dist                    # NSIS 安装包 dist/F1 Hub Setup <版本>.exe
```

### 7.1 本机环境的三个坑（已处置）

1. **`ELECTRON_RUN_AS_NODE=1` 全局存在**（DSH 自身是 Electron 应用）。带着它运行 `electron.exe` 会退化成纯 Node，只打印版本号不开窗口。→ `tools/launch.mjs` 会先删除该变量。
2. **Electron 二进制下载遇 TLS 失败**（`unable to verify the first certificate`）。→ 用 `ELECTRON_SKIP_BINARY_DOWNLOAD=1` 安装，再由 `tools/setup-electron.ps1` 从 `%LOCALAPPDATA%\electron\Cache\electron-v38.8.6-win32-x64.zip` 解包。
3. **pnpm 默认符号链接布局**：`bsdtar` 拒绝「穿过符号链接」解包，且 electron-builder 无法遍历 symlink。→ `pnpm-workspace.yaml` 设 `nodeLinker: hoisted`（扁平 node_modules）。

## 9. 已知限制

1. **新闻与天气依赖网络**，首次加载可能因镜像抖动晚几秒出现；已做「失败重试 + 8s/16s 退避补两次」，仍失败则显示空态而非报错。
2. **实时链路只在积分榜上生效**：赛历、成绩、排位、进站来自内置快照；要更新这些请重跑 `node tools/fetch-data.mjs`。
3. **未做托盘常驻与开机自启**（本次范围外），因此窗口关闭后不会继续提醒。
4. **安装包未签名**，Windows SmartScreen 会提示；`dist/win-unpacked/F1 Hub.exe` 可免安装直接运行。
5. **应用图标为 Electron 默认图标**（未提供 `build/icon.ico`）。
6. `api.jolpi.ca` 为中转镜像，若上游 Ergast 或镜像下线，需要改 `assets/js/config.js` 的 `ENDPOINTS.season` 并重跑采集。
7. **赛历卡片缺官网右下角的赛道轮廓图**：官网每张卡片带赛道线稿，而本地素材只覆盖 5 条赛道（`assets/js/data/track-paths.js` 的 10 条路径里与 2026 赛历 id 重合的仅 shanghai/suzuka/monaco/silverstone/monza；该文件本身零引用，已列入 §2.4 待清理），为避免「张冠李戴」暂不展示，见 §10。
8. **未使用官网专有字体**：`Formula1` / `Formula1Wide` 为专有字体不可分发。拉丁用 Titillium Web（官网正文同款，且 `Formula1` 即其定制版）、中文用阿里巴巴普惠体；两者字形与官网（纯英文站）无法逐字对齐，只求气质一致。
9. **普惠体 Heavy 文件偏小**（1,656,164 字节，其余字重约 6.5MB）：疑为精简子集。已用 `tools/font-preview.py` 验证应用内 148 个汉字全覆盖，但极生僻字可能缺字形。
10. **普惠体 OTF 未压缩为 woff2**（4 个字重合计约 21.6MB）：桌面端从本地磁盘加载无感，但浏览器模式下首屏字体体积偏大；如需优化可用 fonttools 转 woff2 并按 unicode-range 分片。
